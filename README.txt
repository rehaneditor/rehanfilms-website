REHAN FILMS – COMPLETE WEBSITE PACKAGE

FINAL VERSION: 17 VIDEOS + 17 COVERS

Folders/files:
- index.html – main website entry point
- videos/ – 17 web-optimized MP4 portfolio videos
- covers/ – 17 matching cover images
- README.txt – package information

Portfolio mapping:

Playback:
- Every video card uses its own cover image.
- Clicking a cover opens the matching video.
- The player autoplays muted, plays inline, and loops automatically.
- The video poster is the matching cover image.
- New HEVC sources were converted to H.264 MP4.

Web optimization:
The MP4 files in this final website package are web-optimized copies so the package is practical for GitHub/Vercel hosting. The original source uploads remain separate from this package.

Deployment:
Upload index.html, videos/, and covers/ to the GitHub repository root.
index.html is the entry point for Vercel.
